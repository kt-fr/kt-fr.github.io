# Scrapbook revision — 13 November 2026

This is an art-direction revision based on the screencast provided by the user of https://webdesign.kernjosh.com. It is not a copy of that site's code or object photographs. It uses the existing sourced illustrations and Kartik's McQueen photograph.

Changes:
- Warm, slightly irregular paper texture and muted printed-object finish
- Small, quieter personal text and paper-pill navigation
- Composition with deliberate empty space on desktop and a separate phone layout
- 3-phase scroll: objects spread -> intentionally gather and overlap -> spread again
- Paper tape on notebook, slightly battered document, subtler cutout shadows
- Added the real Wikimedia Commons cut-out pliers photo already in the project (`SOURCES.md`)
- McQueen and the Arduino `sonny` Easter egg retained

To apply: from `/home/kartik/sra`, extract this archive and reload the running Astro dev page. For a clean start: `cd website && pnpm dev`. The new overlay file is `src/styles/scrapbook.css`.

The reference relies heavily on real hand-scanned physical objects. CSS treatment alone cannot completely recreate that tactile quality. For a next pass we would need photographed or scanned assets of the user's actual objects, with natural rough cutout boundaries.

Only modified/additive files are shipped. Nothing is pushed or deployed.
