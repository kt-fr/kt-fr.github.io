McQueen

An RC car we turned autonomous. A camera on board, a model running elsewhere.

We put a camera and a Jetson on the car, but kept the model off-board. Frames go out over a mobile link; steering and throttle come back. The model was never the hard part. The loop was.

Everything interesting lived between the machines: a link that drops, a frame that arrives late, a command that's no longer useful by the time it lands. We worked on getting that pipeline running end to end on real hardware.
